# Netflix-Data-Analysis-SQL-
This project analyzes the Netflix Movies and TV Shows dataset (8800 + titles ) using MySQL. I cleaned missing values, fixed multi country entries using recursive CTEs, and used window functions to find top release years and countries.The goal was to practice real world SQL cleaning messy data first, then answering business questions from it.
# Dataset 
Kaggle: Netflix Movies and TV Shows 

## Questions answered 
- Movies vs TV Shows split
- Top countries producing content
- Peak release years
- Longest movies
- Top 3 years per content type
